# Jarvis X Provenance

This repository is maintained as Jarvis X and represents an independently developed and extended assistant implementation.

## Origin Notes

- The project follows common desktop-assistant design patterns (speech input, intent routing, command execution).
- Some early concepts were used as a starting basis before significant customization.
- The current implementation includes substantial additions beyond baseline patterns, including multi-platform scripting, smart-home/network tooling, workflow memory export, expanded integrations, and UI redesign.
